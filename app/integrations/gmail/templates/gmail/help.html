Labels are mapped to tables

When querying a table, "date", "from", "to" and "subject" are returned.

SELECT * FROM YourLabel
SELECT * FROM YourLabel WHERE "From" like '%somebody@example.com%'

Use the special threads view to retrieve a list of messages:

SELECT * FROM threads WHERE "?id" = 'threadId'

Use the special messages view to search across all your messages:

SELECT * FROM messages WHERE "?q" = 'your gmail search query'
